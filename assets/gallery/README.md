# Our Work photos

Drop photos in THIS folder and they automatically appear in the "Our Work"
gallery on the website — no code changes needed.

## How to add photos (from your phone or computer)
1. Go to: https://github.com/gpracer68/the-riders-garage/tree/master/assets/gallery
2. Click **Add file → Upload files**
3. Drag in your photos (JPG or PNG)
4. Click **Commit changes**
5. Wait ~1 minute — they show up on the site.

## Tips
- The caption under each photo comes from the file name. Name files like
  `2023-ktm-topend-rebuild.jpg` and it shows as "2023 ktm topend rebuild".
- To control order, start file names with numbers: `01-...`, `02-...`
- Keep photos under ~3 MB each so the page loads fast.
